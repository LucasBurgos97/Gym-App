# Martin Gym Manager

Sistema de gestión para gimnasios desarrollado con React, Vite y Supabase.

## Objetivos

- Gestión de alumnos.
- Gestión de membresías.
- Registro de asistencias.
- Control de vencimientos.
- Registro de pagos.
- Dashboard con estadísticas.

## Tecnologías

- React
- Vite
- JavaScript
- Supabase
- PostgreSQL
- Git
- GitHub
